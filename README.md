# AI Linkedin Content Generator 🚀  
**Description:** An AI-powered tool that generates new posts based on past content using the **Gemini AI API** and integrates seamlessly with Google Docs.  

## Features  
- Generates contextually relevant posts  
- Saves directly to Google Docs  
- Automates content workflows  

## Tech Stack  
- **Python**  
- **Gemini AI API**  
- **Google Docs API**
